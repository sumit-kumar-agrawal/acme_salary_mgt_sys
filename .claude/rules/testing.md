# Testing Rules

- Test business behavior, not implementation details.
- Cover salary creation and salary history.
- Test filtering and analytics calculations.
- Test authorization and sensitive data access.
- Use factories and synthetic test data.
- Run relevant tests after each change.
- Never claim tests passed unless they were run.
