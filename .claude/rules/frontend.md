# Frontend Rules

- Use React functional components and hooks.
- Use Bootstrap for responsive layouts.
- Keep API calls in the API layer.
- Keep components focused and reusable.
- Handle loading, empty and error states.
- Validate forms and show useful errors.
- Avoid duplicating business logic from Rails.
- Write component tests for important flows.
