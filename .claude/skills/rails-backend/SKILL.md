# Rails Backend Skill

Before making changes:

1. Read docs/requirements.md.
2. Review the existing Rails architecture.
3. Identify the affected models and endpoints.
4. Propose a plan for significant changes.

Implementation:

- Follow Rails conventions.
- Use RESTful endpoints.
- Keep controllers thin.
- Use services for multi-step operations.
- Use query objects for complex analytics.
- Preserve salary history.
- Handle currency explicitly.
- Add tests for new behavior.

After implementation:

- Run relevant RSpec tests.
- Report changed files and test results.
- Identify any assumptions or unresolved questions.
